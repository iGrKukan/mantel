# ShelfTop

Нативная полка для macOS у верхнего края экрана: убирает с Рабочего стола свежие
снимки и записи экрана, показывает их миниатюрами и отдаёт перетаскиванием в любое
приложение. Плюс проигрыватель того, что сейчас звучит, и отправка файла на Google Диск.

Бесплатная альтернатива Droppy, Dropover и Yoink.

## Что умеет

- **Автоперехват захватов.** Снимок экрана исчезает с Рабочего стола за секунду и
  появляется в полке. Обычные файлы не трогаются. Недописанная запись экрана дожидается
  завершения — в полку попадает целый файл.
- **Папки-источники.** Любая выбранная папка (например, «Загрузки»): всё, что в ней
  появляется, попадает в полку. Копией или переносом — на выбор.
- **Перетаскивание наружу.** Из полки в Finder, в мессенджер, на другой рабочий стол.
  Отдаётся настоящий файл, поддерживается выделение нескольких.
- **Google Диск.** Кнопка или перетаскивание на значок Диска — файл уходит в выбранную
  папку Диска. Папка назначения настраивается, подпапки доступны прямо при перетаскивании.
- **Проигрыватель.** Показывает и позволяет управлять тем, что играет в системе —
  Spotify, «Музыка», YouTube в браузере. Плюс воспроизведение аудиофайлов из самой полки.
- **Автоочистка** по сроку хранения, запуск при входе, полка видна на всех рабочих столах
  и поверх полноэкранных окон.

## Требования

macOS 14 и новее. Apple Silicon и Intel.

## Сборка

```
brew install xcodegen
xcodegen generate
xcodebuild -project ShelfTop.xcodeproj -scheme ShelfTop -configuration Release build
```

Или одной командой на удалённую машину: `bash scripts/deploy.sh`.

## Стороннее

Системный проигрыватель использует [mediaremote-adapter](https://github.com/ungive/mediaremote-adapter)
(BSD-3-Clause) — он лежит в `Vendor/mediaremote-adapter` вместе с текстом лицензии.
